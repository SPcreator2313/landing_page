* Color: `#F9FAF8`

* Size: `48px`
* Color: `#F9FAF8`
* Weight: `900` (Black/Heavy)

### 2. Information Section

* **Section Heading** (*Information Header*):
* Size: `36px`
* Color: `#1F2937`
* Weight: `900`

* **Quote Text:**
* Size: `36px`

* **Background Color:** `#3882F6` (matching the button style)

## 🛠️ Workflow & Strategy Tips

1. **Take it one section at a time:** Don't stare at a blank page. Break it down into 4 main sections + footer. Get one section looking solid before moving to the next.
2. **HTML first, CSS second:** Drop all your raw content into the HTML structure first. Once the content is on the page, layer on your CSS. Avoid bouncing back and forth constantly to save frustration.
3. **Leverage Flexbox:** Review your previous Flexbox exercises if you get stuck aligning navigation bars, hero elements, or information cards.
4. **No responsiveness required:** Don't worry about mobile screens, media queries, or resizing. Build it to look great on a standard desktop computer monitor.
5. **Ship it:** Once you are done, push your repository up to GitHub!
